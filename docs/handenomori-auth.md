# ハンデの森の認証付き取得

ハンデの森への実際のデータ取得ごとに新しいセッションを作成し、ログイン、
会員状態の確認、対象ページ取得を行います。ログインセッションは保存しません。
既存の画面データキャッシュ（試合画面は5分など）のヒット時は通信しません。
認証情報の未設定・ログイン失敗時は匿名取得へ切り替えません。

## 本番設定

利用者の承認を得て、リポジトリの Actions Secrets に次を登録してください。

- `HANDENOMORI_EMAIL`
- `HANDENOMORI_PASSWORD`

本番デプロイ時に、両方が設定されている場合のみ権限600のJSONをサーバーの
`/opt/hawks-ai/handenomori/credentials.json` に配置します。
コンテナには `/run/handenomori/credentials.json` として読み取り専用でマウントします。
一部だけ設定されている場合はデプロイを中断します。両方未設定の場合は既存の
サーバーファイルを維持します。認証情報をソース、画像、ログ、成果物に含めないでください。

ローカルの管理用スクリプトでは同名の環境変数、または
`HANDENOMORI_CREDENTIALS_FILE` で指定した秘密JSONの `email` / `password` を使えます。
認証情報が取得できない場合、履歴更新はエラーとしてその日をスキップします。

## 検証

`python -m pytest tests/test_handenomori_client.py tests/test_game_calendar.py`

毎回のログイン、hiddenフォーム値、ログイン失敗、セッション失効、他ホストへの
転送拒否、エラーの秘密情報除去、ホーム/ビジターのハンデ対応をモックで検証します。
実運用ではログイン後の掲載元と試合画面を照合してください。
